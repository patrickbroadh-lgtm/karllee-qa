# Karllee QA

Karllee Construction mobile quality assurance, inspection and snagging application.

This repository is the source of truth for the Karllee QA MVP.

## MVP build order
1. Authentication and Supabase integration
2. Persistent projects, plots and QA inspections
3. Photo/document evidence
4. Automatic snag creation from failed QA checks
5. Subcontractor completion workflow and email notifications
6. Offline sync and audit trail
7. PDF reports
8. Testing, deployment and release documentation
